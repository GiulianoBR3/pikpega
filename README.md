# Sobre o site
Brechó Pik Pega - Infantil e adulto

Nosso site possui 4 páginas;
1 * página de bem vindo, mostrando o que é o brecho 
2 * página mostrando peças de roupas e calçados infantis
3 * página mostrando peça de roupas e calçados adultos
4 * página de contato.

O site é responsível e segue a identidade visual da marca.
